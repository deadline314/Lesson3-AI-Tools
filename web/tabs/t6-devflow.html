開發工作流

知道工具只是第一步，怎麼用才是關鍵。這一章教你完整的 AI 輔助開發流程：從寫 prompt、拆任務、到 debug 和管理 API 額度。

完整 12 步工作流
  1. 需求釐清 — 用自然語言寫下「我要做什麼」+ 驗收標準
  2. 拆解任務 — 把大目標拆成 3-5 個可驗證的子任務
  3. 建立專案 — 用 AI 產出 boilerplate（框架、設定檔）
  4. 設定 AI Context — 寫 CLAUDE.md / .cursorrules
  5. 逐步實作 — 一次只做一個子任務
  6. 每步驗證 — 跑測試 / 看畫面 / code review
  7. Debug — 貼完整錯誤 + context 給 AI
  8. 重構 — 功能做完後請 AI 整理程式碼
  9. 寫測試 — 請 AI 針對邊界條件產測試
  10. 寫文件 — AI 產 README / API doc
  11. PR — 用 AI 產 PR description
  12. 部署 — CI/CD 設定也可以請 AI 幫忙

    System Prompt vs User Prompt

    System Prompt 設定 AI 的「人格」，User Prompt 是具體指令。兩者搭配才完整。

    SYSTEM PROMPT（設定人格）
    你是資深 React 工程師。
    偏好 TypeScript + Tailwind。
    程式碼簡潔，不加不必要的註解。
    有 bug 先解釋原因再給修法。
    USER PROMPT（具體指令）
    幫我寫一個 Modal component，
    支援 ESC 關閉和點擊 backdrop 關閉，
    有 open/close 動畫。

    System Prompt 像是「面試時的 JD」，User Prompt 像是「今天的工作指派」。前者只設一次，後者每次不同。

    Exponential Backoff 指數退避

    當 API 回傳 429 (Rate Limited) 時，不要瘋狂重試——用指數退避：

    async function callWithBackoff(fn, maxRetries = 5) {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      return await fn();
    } catch (err) {
      if (err.status !== 429 || attempt === maxRetries - 1) throw err;
      const delay = Math.pow(2, attempt) * 1000 + Math.random() * 1000;
      console.log(`Rate limited. Retry in ${(delay/1000).toFixed(1)}s...`);
      await new Promise(r => setTimeout(r, delay));
    }
  }
}
