2026 年寫程式有兩大流派：IDE 整合派（以 Cursor 為代表）和 CLI Agent 派（以 Claude Code 為代表）。前者把 AI 嵌進編輯器，打字就有建議；後者讓 AI 擁有終端機的完整控制權，能自己讀檔、改檔、跑測試。兩者不互斥——很多人同時用。

Claude Code Deep Dive

Agentic Loop（代理循環）

Claude Code 不是一問一答——它跑一個持續循環，直到任務完成：

  1. Receive — 接收你的指令或上一輪結果
  2. Decompose — 把大任務拆成子步驟
  3. Select Tools — 決定要讀檔 / 寫檔 / 跑指令 / 搜尋
  4. Execute — 執行工具、拿到結果
  5. Evaluate — 檢查結果是否符合預期
  6. Loop / Report — 沒完成就回到 2；完成就回報

Context Engineering

CLAUDE.md 是你放在專案根目錄的設定檔，讓 Claude Code 認識你的專案。該放什麼：

  • 專案架構總覽
  • coding style / 命名慣例
  • 常用指令（build / test / deploy）
  • 不能碰的檔案或目錄
  • PR / commit message 格式

Permission System（權限系統）

Claude Code 改檔案前會先問你同意。三種模式：

模式行為適合誰風險
Normal（預設）每次改檔前問 Y/N新手、敏感專案低
Accept Edits自動接受檔案修改熟手、信任 AI中
Full Auto連 bash 都自動跑CI/CD、沙盒環境高

新手建議：先用 Normal 模式養成看 diff 的習慣。熟了再開 Accept Edits 加速。

Cursor 三層互動

Cursor 的 AI 功能分三層，自主性由低到高：

  • Layer 1：Tab 補全 — 打字時自動建議下一段程式碼，按 Tab 接受。最低自主性，你完全掌控。
  • Layer 2：Cmd+K — 選取程式碼後按 Cmd+K 給指令，AI 幫你改寫、產生、翻譯那段程式碼。中度自主性。
  • Layer 3：Composer / Agent — 給一個目標，AI 自己找檔案、改多檔、跑終端機。最高自主性。
層級觸發方式影響範圍自主性用的模型
