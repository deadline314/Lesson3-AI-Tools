引導問題 — 找到你的題目
  1. 你日常有什麼重複且無聊的事？
    → 自動化候選（n8n workflow）
  2. 你最近在學什麼，希望有工具幫你？
    → AI 輔助學習工具候選
  3. 你想給誰看這個作品？
    → 面試官：注重品質 / 朋友：注重趣味 / 自己：注重實用
  4. 你有沒有曾經想過「要是有這個就好了」？
    → 最好的題目來源
  5. 你最常花時間在哪個平台？
    → 針對那個平台做工具最有動力做完

MVP 範圍切割器

選一個大想法，逐步砍掉功能直到變成一週能完成的 MVP：

Demo 七步驟
  1. Hook — 一句話說你做了什麼、解決什麼問題（15 秒）
  2. Pain — 展示沒有你的工具時有多痛苦（30 秒）
  3. Demo — Live 操作你的成品（90 秒）
  4. How — 用了什麼工具、怎麼做的（45 秒）
  5. Learnings — 遇到什麼問題、怎麼解決（30 秒）
  6. Next — 如果有更多時間會做什麼（15 秒）
  7. Q&A — 回答問題（剩餘時間）
