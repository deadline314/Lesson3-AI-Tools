自動化工作流 — n8n

n8n 是開源的視覺化工作流自動化工具——用拖拉節點的方式把「事件觸發 → 資料處理 → 動作執行」串成自動化流程。搭配 AI Agent 節點，能在流程中嵌入會思考、會使用工具的 AI，實現智慧自動化。

五大節點類型

n8n 的一切由節點組成，掌握這五類即可應付多數場景：

🎯 Trigger

流程起點。監聽外部事件：Webhook、排程 Cron、信件到達、資料庫變更。

⚡ Action

對外部服務執行操作：發信、寫入資料庫、呼叫 API、上傳檔案。

🧠 AI Agent

智慧節點：內建 ReAct 循環，能思考、呼叫工具、觀察結果再決策。

🔀 Logic

控制流向：IF 條件分支、Switch、Merge 合併、Loop 迴圈、Wait 等待。

💻 Code

用 JavaScript 或 Python 撰寫任何自訂邏輯，完全自由。

Embedding Model vs Chat Model

Embedding Model：把文字轉成一組數字向量（如 1536 維），用於比較相似度、搜尋。費用極低。

Chat Model：接收對話、產生自然語言回答。費用較高。

「今天天氣如何」 → Embedding → [0.021, -0.87, 0.45, ... ×1536]

兩者在 RAG 各司其職：Embedding 負責「搜尋」，Chat 負責「回答」。

AI Agent 節點內部結構

n8n 的 AI Agent 節點由四個子元件組合：

💬 Chat Model

底層 LLM（GPT-4o、Claude、Gemini），負責思考與生成。

🧠 Memory

對話記憶：Window Buffer / Summary / Vector Store Memory。

🔧 Tools

Agent 可呼叫的能力：搜尋、查 DB、執行程式碼、呼叫 API。

📋 Output Parser

將 LLM 回應結構化為 JSON / 表格，方便下游節點使用。

Self-host vs Cloud 決策指南

選 Cloud 如果你：

  • 不熟 Docker / Linux 運維
  • 流程數量少、執行次數在免費額度內
  • 需要快速驗證想法，不想花時間在基礎設施

選 Self-host 如果你：

  • 每月任務數超過 5,000，想省錢
  • 處理敏感資料，需要資料不離開自己的伺服器
  • 需要無限制的執行次數與自訂節點
  • 有基本的 Docker Compose 操作能力

建議路線：Cloud 免費方案練習 → 流程穩定後遷移自架 → 團隊規模用 Docker Compose + Postgres。
