多模態模型：生成 vs 理解

🎨 圖像生成 (Image Generation)

從文字/草圖產生新圖片。代表：Stable Diffusion、DALL-E 3、Flux。

文字 → 潛空間噪聲 → 去噪 → 圖像

👁️ 圖像理解 (Image Understanding)

分析既有圖片內容。代表：GPT-5 Vision、Claude Vision、LLaVA。

圖像 → 編碼器 → Token → LLM 推理 → 文字描述

🔄 雙向多模態

同時能生成與理解。代表：Gemini 3、GPT-5 with DALL-E。

文字 ⟷ 圖像 ⟷ 影片 ⟷ 音訊

DAG（有向無環圖）概念

咖啡類比：泡咖啡時，「磨豆」和「燒水」可以同時進行，但「沖泡」必須等兩者都完成。這就是 DAG——任務有方向、有依賴、但不會循環。

進階節點

LoRA（Low-Rank Adaptation）是一種只有幾十 MB 的微調權重，疊加到基礎模型上就能改變風格。好處是不用重新訓練整個模型。

  • 大小：通常 10-200 MB
  • 疊加：可同時使用多個 LoRA，用權重控制強度
  • 來源：CivitAI 有數萬個社群 LoRA
Load LoRA → strength: 0.7 → 融合到 Checkpoint

ControlNet 讓你用額外的「引導圖」控制生成結構——人體骨架、深度圖、邊緣線稿都可以當輸入。

  • OpenPose：偵測人體姿態，讓角色擺出指定動作
  • Depth：用深度圖控制前後景關係
  • Canny：用邊緣線稿控制物件輪廓
參考圖 → Preprocessor → ControlNet Apply → KSampler

IP-Adapter 用一張圖片取代文字來描述「我要的風格」，讓生成結果繼承參考圖的色調、構圖和氛圍。

  • 適合難以用文字描述的風格
  • 可與文字提示混合使用
  • 權重可調整影響力 (0-1)
參考圖 → IP-Adapter Encoder → 注入到 KSampler

生圖後解析度不夠？ESRGAN 系列模型可以將圖片放大 2-4 倍，同時補充細節。

  • RealESRGAN：真實照片放大首選
  • 4x-UltraSharp：銳利細節最佳化
  • 可搭配 KSampler 做「高清修復」(Hires Fix)
512×512 → Upscale Model → 2048×2048（4× 放大）
