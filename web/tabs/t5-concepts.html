Progressive Disclosure 三層機制

L1 · Metadata

~50 tokens：skill 名字 + 觸發條件。永遠載入。

L2 · SKILL.md

~2K tokens：完整指南。觸發時才讀。

L3 · Deep Files

不定量：scripts + references。需要時才開。

Use this skill when the user asks to write a weekly report,

ReAct 虛擬碼

function agent_loop(goal, tools, memory):
    history = []
    while true:
        thought = llm.reason(goal, history, memory)
        if thought.is_complete:
            return thought.final_answer

        action = llm.select_tool(thought, tools)
        result = execute(action)
        observation = parse(result)

        history.append({thought, action, observation})
        memory.update(observation)

Agent vs ChatBot 關鍵差異

面向ChatBotAgent
控制流人類驅動每一步AI 自主規劃
工具無可呼叫多種
錯誤處理「我不確定」換策略重試
步數固定 1 步動態 N 步
適合問答、翻譯複雜多步任務
Hermes Agent — 會自我進化的 Agent

Self-improving Loop

  1. 接收任務 — 使用者給目標
  2. 執行 — 用工具完成任務
  3. 反省 — 評估自己的表現：哪裡做得好？哪裡可以更快？
  4. 學習 — 把新知識寫成 Skill，下次直接用
  5. 記憶 — 更新長期記憶，記住使用者偏好

Stateful vs Stateless

面向Stateless（一般 LLM）Stateful（Hermes）
記憶範圍僅本次對話視窗跨天、跨月累積
學習能力不會（每次清零）自動產生新 Skills
個人化需手動貼 context自動記住偏好
多平台各平台獨立同一人格跨 Discord/Slack/Web
適合場景一次性問答長期專案助理

名詞字卡 — 進階版

測試你對核心概念的理解。點擊翻面看答案。

MCP 的三層架構是？
Host（AI 應用）→ Client（連線模組）→ Server（工具提供方）
stdio 和 HTTP/SSE 傳輸各適合什麼場景？
stdio：本機工具，簡單快速。HTTP/SSE：遠端服務，可多人共用、需認證。
Skills 的 Progressive Disclosure 是什麼概念？
三層漸進載入：L1 永遠載入（~50 tokens）、L2 觸發時讀（~2K）、L3 需要時才開。像 lazy loading。
JSON-RPC 2.0 在 MCP 中的角色？
MCP 的底層通訊格式。標準化的 JSON 請求/回應結構，任何語言都能實作。
Prompt Caching 是什麼？有什麼好處？
把重複使用的 prompt 前綴快取起來，下次呼叫時不用重新處理。省 token 費用、降低延遲。
RAG 是什麼的縮寫？解決什麼問題？
Retrieval-Augmented Generation。先從知識庫檢索相關資料，再讓 LLM 基於這些資料生成回答。解決 LLM 知識過時和幻覺問題。
模型 Quantization（量化）是什麼？
把模型參數從高精度（FP16）降到低精度（INT8/INT4），大幅縮小模型檔案、降低記憶體需求，代價是微小的品質損失。
MCP 的 Sampling 能力是什麼？
Server 反過來請求 Host 的 LLM 做推理。讓 Server 也能利用 AI 能力，而不只是被動提供工具。
Hermes 的 Self-improving Loop 有哪些步驟？
接收任務 → 執行 → 反省表現 → 學習（寫成 Skill）→ 更新記憶。越用越強。
Agent 的 ReAct 模式全稱？核心概念？
Reasoning + Acting。先推理（Thought）→ 行動（Action）→ 觀察結果（Observation）→ 循環直到目標達成。
為什麼 Skills 比 fine-tuning 更實用？
Skills 是純文字檔，改 Markdown 就好，零成本、即時生效。Fine-tuning 要準備資料集、花錢訓練、不好修改。
MCP 的 Elicitation 能力是什麼？
Server 在執行過程中向使用者詢問額外資訊（如確認刪除、選擇選項），實現人機互動而非盲目執行。

實戰：連接 Google Drive MCP
  1. 找到 MCP Server — 在 mcp.so 或 GitHub 搜尋 "google-drive-mcp"
  2. 安裝 — npm install -g @anthropic/mcp-google-drive
  3. 設定 OAuth — 到 Google Cloud Console 建立 OAuth credentials
  4. 加到 Host 設定 — 在 claude_desktop_config.json 加入 server 設定
  5. 認證 — 首次啟動會跳出 Google 登入視窗
  6. 使用 — 對 Claude 說「讀我 Drive 裡的 spec 文件」
// claude_desktop_config.json
{
  "mcpServers": {
    "google-drive": {
      "command": "mcp-google-drive",
      "args": ["--credentials", "~/.config/gcp/oauth.json"]
    }
  }
}
